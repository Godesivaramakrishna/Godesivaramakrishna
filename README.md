`Java 21` `Spring Boot` `React` `Tailwind CSS` `AWS` `Docker` `Terraform` `Jenkins` `MySQL` `Groq AI`

### [HireFusion AI](https://github.com/Godesivaramakrishna/HireFusionAI)

**Serverless resume and interview analysis platform**

Uses an event-driven workflow to process uploaded resumes and support automated analysis through AWS services. The architecture connects storage events, Lambda processing, AI services, and DynamoDB results.

`Python` `JavaScript` `AWS S3` `AWS Lambda` `Amazon Textract` `Amazon Rekognition` `DynamoDB`
